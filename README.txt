QUICKDROP DELIVERY WEBSITE

Files:
- index.html
- style.css
- script.js

How to run:
1. Keep all 3 files in the same folder.
2. Double-click index.html, or use VS Code Live Server.
3. No internet connection is required. This website uses system fonts only.

Notes:
- The order form is a front-end demo and does not send data to a server.
- Phone number, email, testimonials and brand name are sample content.
- You can rename QuickDrop and replace the contact details before submission.
- This is suitable for your DevOps capstone because it can be containerized with Nginx and deployed through Jenkins/Docker/AWS EC2.
